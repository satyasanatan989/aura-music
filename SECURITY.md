# Security Policy

## Supported Versions

We provide security updates for the latest active release branch:

| Version | Supported          |
| ------- | ------------------ |
| 8.x     | :white_check_mark: |
| < 8.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Aura Music, please do not file a public issue.

Instead, please send an advisory report to the maintainers or open a [Private Security Advisory](https://github.com/realidkroo/mochy-music/security/advisories/new) directly through GitHub.

Please provide:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Affected device architecture / Android version.

We appreciate your responsible disclosure and will acknowledge receipt within 48 hours.
